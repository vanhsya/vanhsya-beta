## Quick start

### Prerequisites

- Node.js 18+
- npm or yarn
- Gemini API key

### Install

```bash
git clone https://github.com/vanhsya/vanhsya-beta.git
cd vanhsya-beta
npm install
```

### Configure environment

```bash
cp .env.example .env.local
```

Then set your own key:

```bash
GEMINI_API_KEY=your_key_here
```

### Run

```bash
npm run dev
```
